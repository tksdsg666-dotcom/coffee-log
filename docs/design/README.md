# 咖啡记录 App

一个给自己喝咖啡留痕迹的 App。不是给咖啡师做的萃取实验记录本，是生活记录——今天喝了什么、在哪喝的、好不好喝、拍一张。愿意的时候可以把粉量水温写全，不愿意的时候只留一个「今天在 Manner 喝了杯冰美式，4 星」也成立。

两种日常：在店里买一杯，和在家自己做一杯。前者不知道参数，后者想记细节。整个设计围绕这个分叉展开——打开记录页第一件事就是选「门店」还是「自制」，选门店参数自动清空，选自制才展开器具、磨豆机、粉水比这些。

回看的部分很轻：一条按天分组的时间线，一个豆子库，一页简单统计。豆子库能看出「这支埃塞我打过 5 星的三杯，参数差在哪」——这是目前唯一带一点分析意味的功能，其余都是如实记录。

## 这个包里有什么

| 文件 | 用途 |
| --- | --- |
| `咖啡记录 App.dc.html` | 完整可交互原型，浏览器直接打开 |
| `SPEC.md` | 数据模型、参数配置、交互规则、设计 token |
| `_ds/organic-.../styles.css` | 设计系统 token（颜色、字体、间距、圆角、阴影） |
| `_ds/organic-.../readme.md` | Organic 设计系统说明 |
| `support.js` / `ios-frame.jsx` / `image-slot.js` | 原型运行时和手机外框，**不用移植** |

原型是网页，用来看清每个状态长什么样、怎么流转。落地时照着 `SPEC.md` 用原生组件重建：导航栏、Tab、底部 Sheet、滚轮选择器、分段控件都换成系统的。原型没做持久化、输入法、手势、无障碍。

假数据有 28 条记录（2026 年 8 月）、7 支豆子、4 个来源、6 台设备，覆盖了所有做法和边界情况，可以直接抄成种子数据。
