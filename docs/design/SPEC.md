## 数据模型

### Record

```
id        string
mon, d    int       月、日（旧数据 mon 缺省为 8）
t         string    "HH:MM"
m         string    做法枚举
s         string    来源 id，'self' = 自制
b         string?   豆子 id，可空
ice       bool?     true = 冰
r         int?      1-5 整星，可空
note      string
photo     string?   照片 id
gear      string?   冲煮器具名，仅 m='滴滤' 且 s='self'
grinder   string?   磨豆机名，同上
gunit     string?   研磨单位，随磨豆机存下来（格/圈/档）
dose      float?    粉量 g
water     float?    水量 g（滴滤/冷萃）或加水 ml（美式）
yieldG    float?    浓缩液重 g
milk      float?    奶量 ml（奶咖）或其他液体 ml（特调）
grind     float?    研磨刻度
tempC     int?      水温
sec       int?      时间（秒）
hours     int?      浸泡小时
```

**所有参数字段可空，空值不写入记录**，显示时不占位。

### Bean

```
id, name?, origin?, region?, farm?, variety?
process?    处理法，5 预设 + 自由填写
roast       浅烘 / 中浅烘 / 中烘 / 中深烘 / 深烘
season?     产季，如 2025-2026
agtron?     烘焙色值
roastDate?  烘焙日期
roaster?, flavor?
mine        true = 我的豆子
swatch      图标色
```

**显示名**：`name` 有值用它，否则 `origin + ' ' + (farm || region)`，都没有则「未命名豆子」。
**副标题**：`[roaster, farm ? region : '', variety, process, roast]` 过滤空值后 ` · ` 连接。
**创建校验**：name / origin / farm 至少一个有值。
**属性表顺序**：产地 · 产区 · 庄园 · 品种 · 处理法 · 产季 · 烘焙度 · 烘焙色值 · 烘焙日期 · 烘焙商 · 风味 · 归属。

### Brand

`id`（`self` 保留）· `name` · `self: bool`。只有名称一个可填字段。

### Device

`name` · `kind` · `brew` / `grinder`（派生自 kind）· 磨豆机额外有 `gstep` `gmin` `gmax` `gdef` `gunit`。

| kind | 归属 |
| --- | --- |
| 滤杯 / 滴滤机 / 浸泡滤杯 / 咖啡机 | 冲煮器具 |
| 手磨 / 电动磨 | 磨豆机 |
| 电子秤 | 仅清单 |

设备表是单一数据源，记一杯的器具和磨豆机选项从它实时过滤。

## 做法与参数

```
METHODS = ['滴滤', '美式', '奶咖', '冷萃', '特调 & 其他']
```
3 列网格，第五项跨 2 列。

| 做法 | 字段（标签 / 单位 / 步长 / 下限 / 默认） | 比例 |
| --- | --- | --- |
| 滴滤 | dose 粉量 g .5/5/15 · water 水量 g 5/50/240 · grind 研磨（随磨豆机）· tempC 水温 °C 1/60/92 · sec 时间 mm:ss 5/30/140 | 粉水比 `1:water/dose` |
| 美式 | dose 粉量 g .5/5/18 · yieldG 浓缩液重 g 1/5/36 · water 加水 ml 10/0/120 · sec 时间 秒 1/5/27 | 萃取比 `1:yieldG/dose` |
| 奶咖 | dose 浓缩粉量 g .5/5/18 · yieldG 浓缩液重 g 1/5/36 · milk 奶量 ml 10/30/180 | 奶咖比 `1:milk/yieldG` |
| 冷萃 | dose 粉量 g 5/10/60 · water 水量 g 50/100/600 · hours 浸泡 小时 1/1/14 | 粉水比 |
| 特调 & 其他 | dose 粉量 g .5/5/18 · yieldG 浓缩液重 g 1/5/36 · milk 奶/其他液体 ml 10/0/120 | 液体比 `1:milk/yieldG` |

分子或分母为空时比例显示 `—`。一位小数。

### 研磨刻度

不同磨豆机精度不同，刻度跟着当前磨豆机走：

| 磨 | 步长 | 量程 | 单位 | 默认 |
| --- | --- | --- | --- | --- |
| Comandante C40 | 1 | 5–40 | 格 | 24 |
| 幻刺 Pro | 0.1 | 3–12 | 圈 | 5.6 |
| Fellow Ode Gen2 | 1 | 1–11 | 档 | 7 |

换磨时研磨值重置为该磨默认值；渲染和保存都按量程钳制并对齐步进。记录里存 `gunit`，所以历史记录始终显示自己的单位。

添加磨豆机时要填刻度精度（整数 / 一位小数）和量程。

**研磨的交互是一张独立卡片**（仅滴滤 + 自制时出现），不在参数列表里：常用值胶囊（取该磨的历史刻度，最近 4 个）+ 拖动条 + 两端 ±。大数字可点清空。

## 记一杯：字段顺序

顺序是设计结论，不要重排：

1. 来源分段（门店 / 自制）
2. 沿用最近（仅自制，3 个预设，只取自制记录）
3. 做法 + 冰/热
4. 豆子（点开 sheet）
5. 冲煮器具 / 磨豆机（仅 滴滤 + 自制）
6. 参数（标题右侧实时比例，左侧「全部留空」）+ 研磨卡片
7. 评分（5 星，52×52）
8. 品牌 chips + 新品牌（仅门店）
9. 照片
10. 备注
11. 时间

### 来源切换的副作用

| 操作 | 结果 |
| --- | --- |
| 选门店 | 五个做法的参数**全部**清空，之后切做法也保持空 |
| 选自制 | 恢复当前做法默认值 |
| 门店下切做法 | 新做法参数也清空 |
| 选门店 | 隐藏「沿用最近」和器具/磨豆机 |
| 保存 | 门店记录不写 gear / grinder |

### 参数留空

点数字清空 → 灰色 `—`；再点 ± 恢复默认值（不是从 0 加）；「全部留空」清整组；保存时过滤所有 null。

### 时间

表单里是一行摘要（`8 月 26 日 · 周三` / `今天` / `09:41`），点开三列滚轮 sheet：日期（今天、昨天，往前 60 天，跨月正确）、时、分（5 分钟一档）。左上「现在」，右上「完成」。每次打开表单重取当前时间。不能选未来。

### 照片

「＋ 加一张照片」→ 拍照 / 从相册选 动作面板。已加照片显示预览 + 移除。时间线卡片显示缩略图，详情页大图。原型里是可拖入的空占位框。

## 关键界面规则

### 时间线

按 `mon*100 + d` 降序分组。组标题「8 月 26 日」+ 副标题（今天 / 昨天 / 周三）。

卡片：豆子名（点进豆子详情）+ 副标题 / 星级 / 时刻 / `⋯` 删除 → 标签行（做法胶囊带色点、比例、来源胶囊点进品牌详情）→ 照片缩略图 → 参数串 → 备注。整卡可点进记录详情，子元素点击需 stopPropagation。

参数串顺序：器具 → 粉量 → 水量/加水 → 液重 → 奶/液体 → 研磨（前缀磨豆机名）→ 水温 → 时间 → 浸泡。例：「Fellow Ode Gen2 7档」。

新保存的卡片底色高亮一次。

### 统计

三块，全用圆点矩阵（13px 圆点，6px 间距，flex-wrap）：各做法（按杯数降序，取做法色）、冰 vs 热（热 accent / 冰 accent-2）、评分分布（5→1 星）。

### 豆子详情

头像 + 名称 + 烘焙商 → 三宫格（杯数 / 平均评分 / 高分常用比例）→ 图标颜色（6 个棕色系一行 + 自定义 hex/rgb 输入一行）→ 属性表 → **5 星并列对比** → 全部记录 → 删除。

5 星对比：取该豆子所有 5 星记录，按第一条的做法筛选，最多 3 杯并列。差异行高亮。三杯磨豆机不同时研磨行不判差异（单位不同不可比）。

删除：确认后**连带删除该豆子的所有记录**。

### 选豆子 sheet

三组：最近用过（最多 3）/ 我的豆子 / 门店豆子。按入口区分文案：

| 入口 | 标题 | 按钮 | 详情 | 添加后 |
| --- | --- | --- | --- | --- |
| 记一杯 → 选豆子 → ＋ | 选豆子 | 添加并选中 | 收起 | 选中带回 |
| 豆子页右上 ＋ | 豆子 | 添加豆子 | 展开 | 不改选中 |

### 字体

`--font-heading` Caprasimo — **所有数字**（杯数、比例、参数值、时刻、统计）
`--font-body` Figtree — 拉丁文字
中文回退 PingFang SC / Hiragino Sans GB / Microsoft YaHei

数字用 Caprasimo 是这个设计的主要视觉特征。

### 字号

30/700 屏幕大标题 · 26 本月杯数 · 22-24/700 详情标题 · 19 参数值 · 17/600 导航标题 · 16/600 卡片豆子名 · 15/500-600 列表行 · 14 chips · 13 侧标签 · 12/600 分组标题（`letter-spacing: 0.1em`）· 11.5 三级说明

### 圆角

999 按钮/chips/输入框 · 28 sheet · 26 摘要卡 · 22 统计卡 · 20 记录卡/列表容器 · 18 小卡 · 14 滚轮项 · 12 可点数字

### 其他

- 触控目标 ≥ 44×44（负边距扩大点击区，不改视觉）
- 毛玻璃 `color-mix(in srgb, var(--color-bg) 94%, transparent)` + `blur(20px)`
- 分隔线 `1px solid color-mix(in srgb, var(--color-text) 7%, transparent)`
- 阴影 `--shadow-sm`（卡片）/ `--shadow-lg`（浮动按钮、sheet）
- 布局一律 flex/grid + gap
- 图标用 Lucide，`stroke-width: 2.75`。Tab 三个图标：`list` / `coffee` / `user`

## 已确认的产品决策

1. 做法和来源是独立字段，任意组合
2. 来源只区分自制和品牌，不记门店地点
3. 评分 1-5 整星，不要半星
4. 不选「最好喝的一杯」，用「5 星的 N 杯并列对比」
5. 空字段直接隐藏，不显示占位符
6. 统计不用图表，用圆点矩阵
7. 处理法支持自由填写
8. 研磨度必须和磨豆机绑定显示
9. 门店记录默认全部参数为空
10. 统计先做基础的，深入分析后续再说
